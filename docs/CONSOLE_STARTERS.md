# 웹 콘솔 탐지 시작 자료

0.15.0 이전에도 엔드포인트 탐지 라이브러리 962개와 일반 상관 탐지 시작 템플릿 3개가 제공됐다. 962개는 Windows 458개, Linux 454개, 가상 실험 50개이며 임계값 920개·순차 행동 42개로 구성된다. 소스 팩의 원래 활성 메타데이터 547개는 xSERA의 활성 정책 수가 아니다. 기존 라이브러리 가져오기는 비활성이고 테넌트 정책 한도는 200개다.

0.15.0에는 연결 분석 시작 템플릿 **8개**를 별도 제공한다. 기존 965개와 새 8개는 항목 수이며, 서로 독립적인 공격 기법 수·탐지 효과·활성 정책 수를 합산한 값이 아니다. 새 설치에 정책이나 모델을 자동 등록·활성화하지 않는다.

| 시작 템플릿 | 확인할 원본 |
| --- | --- |
| 인증 실패·성공 관측 2개 | 정규화된 `raw.security.action=authentication`과 `outcome=failure/success` |
| 엔드포인트 프로세스 생성·파일 삭제·네트워크 연결 관측 3개 | `aegis:endpoint`, `aegis.endpoint.v1`, 해당 원본 행동 필드 |
| 네트워크 차단 보고 관측 1개 | 정규화된 `network_connection/blocked`; 새 차단을 실행하는 동작이 아님 |
| CPU 모델 신호 + 단일 근거 1개 | 정확한 활성 모델 ID와 활성 단일 정책 1개 |
| CPU 모델 신호 + 두 근거 1개 | 정확한 활성 모델 ID와 서로 다른 활성 단일 정책 2개 |

`GET /api/v3/intelligence/templates`는 8개 항목·필수 입력·한계를 반환한다. `POST /api/v3/intelligence/templates/{id}/preview`에 실제 인덱스를 지정한다. 복합 템플릿은 `model_rule_id` (`ml:sequence:{id}` 또는 `ml:{id}`), `parent_policy_ids`, 선택한 연결 기준을 추가한다. 기본값은 `enabled:false`, `create_case:false`, `window:300`, `join_on:entity`이다. 임의 조건·분류 정답·모델 가중치·넓은 모델 종류 선택을 받지 않는다.

미리보기는 현재 사용자·테넌트·전체 인덱스 권한을 확인한다. 모델의 현재 독립 활성 승인·소유자·검토자와 GRU 학습 소스 권한을 재확인하고, 단일 부모 정책의 현재 활성 승인·개정·소유자·검토자·전체 인덱스 범위를 확인한다. 입력 모델과 모든 부모의 인덱스를 완전히 선언해야 한다. 미리보기는 정책·신호·사건·장치 대응을 생성하지 않는다.

반환된 `definition`을 기존 `POST /api/v3/intelligence/policies`로 저장하면 서버가 모델·부모 개정을 새로 고정한 검토 대기 초안을 만든다. 활성 실행을 요청한 초안도 다른 분석가가 해당 개정을 독립 승인해야 작동한다. 수정 시에는 승인과 고정 입력을 새로 검토한다. 모델·부모·권한이 변경되면 현재 승인 검증을 우회할 수 없다.

`create_case:true`를 명시적으로 선택한 복합 템플릿은 정확한 호스트 식별 근거를 요구하는 Case 어댑터를 포함한다. 모델을 포함한 2개 또는 3개 입력의 원본이 겹치지 않는 묶음 조건을 검사하고, 정책 가중치 75를 사용한다. 이 값은 악성 확률이 아니다. 원본의 비중복은 통계적으로 독립적인 장치·센서, 인과관계 또는 공격 성공을 증명하지 않는다. `flow` 결합은 보고된 주소·연결 관계이므로 실제 장치와 NAT·시간 정보를 검토해야 한다. 어떤 템플릿도 자동 대응이나 실제 호스트·네트워크 차단 권한을 부여하지 않는다.

기존 1,536개 합성 시퀀스는 24개 유형과 유형별 64개 변형의 교육·평가 자료다. 학습 1,024개·보정 256개·별도 평가 256개로 분리되며 실제 위협 탐지율을 보증하지 않는다. 콘솔 관리형 데이터세트, 샘플 등록·편집과 개정 기능은 별도 데이터세트 화면에서 제공한다. 자료 삭제는 원본 로그 또는 기존 모델·Case 증거를 삭제하는 작업과 구분한다.

xSERA 0.17 운영 안내
===================

웹 콘솔의 탐지·대응 > 확장 분석·연구에서 외부 센서, 파일 분석 엔진,
행위 연구, 온라인 이상치와 Sigma 변환을 관리한다. 기존 YARA 규칙·자료
관리·단일 및 복합 탐지 화면도 유지한다.

파일 분석: 기존 에이전트가 원본 프로세스 identity와 실행파일 hash를
검증하여 전달한 완료 증거 파일을 선택한다. capa/FLOSS는 별도 유계 CPU
작업자가 자동 검사한다. capa는 기본 Apache-2.0 규칙 1,042개를 해시로
핀하며 기능을 설명한다. FLOSS는 문자열을 추출한다. 두 결과만으로
악성을 단정하지 않는다. Speakeasy는 에뮬레이션 관찰 범위를 표시한다.
CAPE는 구성된 별도 서버와 파일별 독립 전송 승인, ClamAV는 clamd가 필요하다.
해당 환경이 없으면 unavailable로 표시하고 다른 분석을 계속한다.
파일별 Case·원본·SHA·엔진 버전·규칙 해시·캐시 여부를 결과에 기록한다.

센서: Suricata EVE, Zeek JSON, Falco JSON, Tetragon JSON, osquery 결과를
등록한 source 범위로 수집한다. 다른 관리자가 수집·탐지 범위를 검토한다.
기존 Windows/Linux/FortiGate/Cisco 수집도 계속 지원한다. 배포 조각과
읽기 전용 전달기는 deploy/analysis-sensors 및 tools/forward_analysis_sensor.py에 있다.
센서 보고 JSON을 받았다는 사실은 패킷/커널 포착 성공을 인증하지 않는다.
손실·상태 보고를 별도로 보며 재생 자료는 virtual-lab으로 구분한다.

행위 연구: 정상 training 16~1024개와 validation 8~256개를 시간순으로
분리해 PyTorch CPU 관계 예측을 학습한다. 24개 특징에는 ground-truth나
이벤트 ID, 정답 action을 넣지 않는다. semantic ablation, 빈도 baseline,
seed별 손실을 제공한다. 시간 그래프·유계 장기 스케치·인과 경로 요약과
Windows 설명 잡음 축약을 함께 산출한다. 실제 탐지 반영은 독립 검토에서
live를 선택해야 한다. 모델·정상 기준·입력 원본은 인증 source receipt와
현재 권한·개정·특징 계약 해시를 검증한다. generic 원본의 source 주장은
권위로 사용하지 않는다. 논문 원형 GNN·탐지율 재현이나 완전한 인과 복원은 아니다.

온라인 이상치: river 0.26.1의 실제 Half-Space Trees를 검토한 정상 원본
16~32개로 학습하고 다른 관리자가 승인한다. 운영 원본은 예측과 ADWIN
분포 변화 감지에만 사용한다. 수동 선택 분석은 shadow로 격리하여 운영
ADWIN 이력·커서·탐지 신호를 바꾸지 않는다. 운영 입력의 미인증/만료
원본은 이유를 기록하고 제외한다. 모델 권한·정상 기준 source 철회 시
운영 처리를 중단한다. 이상 점수와 변화는 악성 확률이 아니다.

실시간 시퀀스: 기존 GRU의 [batch,time,features] 모델에 지연 허용 정렬,
중첩 창·유휴 완료를 선택 설정한다. 프로필과 현재 모델 활성 승인 세대를
독립 검토한다. 모델 교체·중지·프로필 변경 시 이전 세대의 버퍼·대기 작업을
탐지 근거로 재사용하지 않는다. 원본 센서 시각 동기화를 보장하지 않는다.

Sigma: 선택 sigma-analysis extra의 pySigma 2.0.1 AST로 pysigma-json-v3를
변환한다. 명시적 field/logsource 매핑이 필요하다. AND/OR/NOT, 목록,
contains|all, typed 비교, raw 존재 여부, 필드 참조, 제한 RE2를 지원한다.
미지원 modifier·집계/상관 규칙·배열 의미를 조용히 제거하지 않고 거절한다.
미리보기의 질의를 검토하고 기존 정책 관리에서 별도 탐지를 구성한다.
기존 scalar-v1/bounded-json-v2 계약을 바꾸지 않는다.

보존: 정상/Shadow 상세는 최근 128개와 해당 기능의 24시간 기준으로
정리한다. 입력 해시·실행 ID·판정·감사 이력은 남긴다. live 이상·Case
근거·bookmark·법적 hold는 보호한다. 정상 학습 참조는 모델의 독립 폐기
절차 후 해제하며 원본을 즉시 삭제하지 않는다. 점수 이력은 최대 512개,
추론 그래프·버퍼·모델 캐시는 유계다. 자세한 기능별 계약은 별도 가이드를 따른다.

설치: ml-cpu / sigma-analysis / online-analysis는 선택 extra다.
capa/FLOSS/Speakeasy는 분석 전용 환경의 XSERA_ANALYSIS_SITE_PACKAGES를
서버에서 지정하는 방식을 권한다. 임의 사용자 명령·경로를 실행하지 않는다.
기본 서버 의존성과 파일 엔진의 전이 의존성 충돌을 분리한다.

범위: 외부 엔진 라이선스와 배포 의무는 각 번들 출처/라이선스와 별도로
검토한다. NodLink의 상용 제한 원본 코드는 포함하지 않는다. Yocto 자체 OS는
현재 배포 준비 구조를 유지하며 실장비 이미지·드라이버 인증은 별도다.
합성 시뮬레이션과 코드 회귀는 실제 공격 탐지율·장기 오탐률·지속 부하나
상용 센서의 무손실 포착을 증명하지 않는다. 실제 차단·격리·삭제·종료 명령은
이번 보강과 시험에서 실행하지 않는다.

관리형 참조표와 위협 인텔리전스
==============================

같은 테넌트의 분석가와 관리자가 표를 조회하고 관리자만 저장한다. 이 화면은
서버 내부의 관리형 스냅샷을 편집한다. 외부 피드를 자동 수집하거나 URL과
자격 증명을 등록하는 화면이 아니다. 참조표 이름과 열은 단순 식별자여야 한다.

1. 새 참조표에서 이름, 유형과 고유한 문자열 키를 고른다.
2. 열을 추가하거나 이름을 바꾼 뒤 행을 추가한다. 셀마다 문자, 숫자, 참/거짓,
   null 또는 필드 없음 유형을 선택한다. 참/거짓은 true 또는 false다.
3. 인텔리전스 유형은 IP, 도메인 또는 MD5/SHA1/SHA256 해시다. IP와 도메인,
   해시 값은 서버에서 형식 확인·정규화한다. 모든 지표 키는 고유해야 한다.
4. 인텔리전스에는 confidence 0–100, 출처(provenance), 미래 만료 시간이
   필요하다. 신뢰도는 운영자가 제공한 값이며 제품이 계산한 탐지 점수가 아니다.
5. 저장하면 전체 스냅샷이 버전 확인 후 갱신된다. 편집과 삭제는 저장 전 초안에만
   적용된다. 다른 관리자가 먼저 저장하면 충돌을 확인하고 다시 불러온다.

최대 10,000행, 20열, 2MiB, 테넌트당 100개 표다. 화면은 20행씩 편집한다.
null과 필드 없음은 다른 상태로 보존한다. 브라우저에서 정확히 보존할 수 없는
큰 정수 또는 중첩 값이 있으면 해당 표의 저장을 차단하고 읽기만 제공한다.

만료된 표는 검색 보강에 사용할 수 없다. 검색에서 명시적으로 lookup 명령을
사용할 때만 이벤트를 보강한다. 지표 목록에 존재한다는 사실만으로 공격이
확정되지 않는다. 원본 이벤트의 테넌트와 인덱스 권한은 검색 단계에서 적용된다.
